Icons in Assets/Icons are from the Iconsax library (rounded, linear), vendored as separate
SVG files. Styles/IconData.xaml holds the same strokes as path data and is generated by
tools/gen_icons.py from tools/icons.map. Nothing references the library path at runtime.
Directional affordances use only the chevron glyphs (arrow-down4, arrow-up3, arrow-right4);
the left chevron is the right chevron mirrored, because the rounded linear set has no arrow-left4.

Iconsax is licensed by its authors (https://iconsax.io); keep this notice with the files.

The text editing glyphs (bold, italic, link, list-bullet, list-number) do not exist in rounded/linear, so they come from
the closest match in rounded/outline (filled shapes drawn in the foreground colour). list-number is the checklist glyph,
the nearest numbered list in the set. close-plain is the plain close glyph from rounded/linear/arrow2.
